# QuickBus (LankaBus) 🚌
**Local Bus Ticket Booking & Seat Management System**

QuickBus is a modern, interactive web application designed to streamline local bus seat bookings in Sri Lanka. It provides a real-time platform for passengers to select and reserve their preferred seats, making travel planning efficient and hassle-free.

## 🚀 Technologies Used

* **Frontend Framework:** React, TypeScript, Vite
* **UI & Styling:** Tailwind CSS, shadcn/ui
* **Backend & Database:** Supabase

## ⚙️ Key Features

* Real-time seat availability and status tracking
* Interactive and user-friendly seat map UI
* Secure user booking and reservation system
* Responsive design for both desktop and mobile devices
